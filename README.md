A free, open-source desktop application for Linux and Windows that shows what your subscriptions really cost — per week, per month, and per year.

The problem
Ten here, a hundred and ninety-nine there. One by one, subscriptions seem small, but together they quickly become one of the biggest fixed costs in a household. Some are charged weekly, most monthly, and a few once a year. That makes it hard to see the whole picture.

What it does
Unified view — converts all your subscriptions to the same scale (weekly, monthly, yearly) and shows the total.
Visual breakdown — a donut chart where each category has its own colour, with subtotals per category (amount, number of subscriptions, share of total).
Ten built-in categories (streaming, cloud storage, AI, audiobooks, etc.) plus support for your own custom categories.
Seven languages and seven currencies.
Privacy-first
No account. No internet connection required.
No ads. No tracking.
All data is stored locally in a plain JSON file (~/.config/SubTrack/subtrack-data.json on Linux, %APPDATA%\SubTrack\subtrack-data.json on Windows). Easy to back up or move to another computer.
